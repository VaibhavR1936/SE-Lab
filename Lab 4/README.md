# Real-Time Endless Runner Game

A Pygame-based endless runner completed according to the project tasks.

## Features

- Player jumps using Space, Up, or W.
- Gravity returns the player to the ground.
- Obstacles spawn and move from right to left.
- Speed gradually increases but has a difficulty-specific maximum.
- Swept collision detection prevents fast obstacles from skipping through the player.
- Score increases when an obstacle is successfully cleared.
- Game-over screen displays the final score.
- Replay using the same difficulty.
- Difficulty selection:
  - Easy
  - Medium
  - Hard
- Sound effects for jumping, scoring, and game over.
- No external sound files are required; short tones are generated by Pygame.

## Setup

Python 3.10+ is recommended.

```bash
pip install -r requirements.txt
```

Run:

```bash
python main.py
```

## Controls

### Menu

- `1` - Easy
- `2` - Medium
- `3` - Hard
- `Esc` / `Q` - Quit

### During gameplay

- `Space` / `Up` / `W` - Jump
- `Esc` - Return to menu

### Game Over

- `R` / `Enter` / `Space` - Replay same difficulty
- `1` - Restart on Easy
- `2` - Restart on Medium
- `3` - Restart on Hard
- `Esc` / `Q` - Return to menu

## Fixes and completed tasks

### Task 1: Collision Detection

The original implementation increased speed forever and checked collision only at the obstacle's final position after movement. This could allow an obstacle to pass through the player between frames.

The fixed version:
- Caps the maximum speed.
- Stores each obstacle's previous position.
- Builds a swept rectangle from the previous and current positions.
- Checks that swept area against the player.

### Task 2: Game Over

A dedicated game-over screen now:
- Displays "GAME OVER".
- Shows the final score.
- Shows the selected difficulty.
- Waits for user input.

### Task 3: Replay and Difficulty

The game supports Easy, Medium, and Hard. Each difficulty changes:
- Starting speed.
- Spawn interval.
- Speed increase.
- Maximum speed.

The game can be restarted without closing Pygame.

### Task 4: Sound

Generated Pygame tones are used for:
- Jumping.
- Scoring.
- Game over.

The game still runs if the system cannot initialize audio.
